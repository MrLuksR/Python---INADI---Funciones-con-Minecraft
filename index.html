02

Descubrí la solución: funciones

Una función permite agrupar instrucciones con un nombre y ejecutarlas cada vez que la llamamos.

Modelado docente

Definir no es ejecutar

funcion_simple.py
def mostrar_menu():
    print("=== MINECRAFT ===")
    print("1. Ver inventario")
    print("2. Recolectar")

mostrar_menu()

def crea la función; mostrar_menu() la llama. El cuerpo de la función lleva sangría.

Predicción: si quitamos la última línea, ¿se muestra el menú?
Ver respuesta y explicación
No. Python conoce la función, pero no ejecuta su contenido hasta que alguien la llama con mostrar_menu().
Ilustración / esquema

¿Cómo circula la información?

LLAMADAmostrar_inventario(10)
→
PARÁMETROesmeraldas = 10
→
EFECTOprint(...)
funcion_con_parametro.py
def mostrar_inventario(esmeraldas):
    print("=== INVENTARIO ===")
    print("Esmeraldas:", esmeraldas)

mostrar_inventario(10)
mostrar_inventario(25)

La misma función muestra valores diferentes sin duplicar su código.

Un paso más: devolver valores

¿Qué cambia entre print y return?

print() muestra un mensaje en pantalla.

Muestra un valor
def saludar():
    print("Hola")

saludar()

return entrega un resultado para utilizarlo fuera de la función.

Devuelve un valor
def recolectar(esmeraldas):
    return esmeraldas + 5

esmeraldas = 10
esmeraldas = recolectar(esmeraldas)
Importante: return no actualiza por sí solo la variable externa. Por eso se escribe esmeraldas = recolectar(esmeraldas) para guardar el nuevo valor.

MISIÓN 01 · SIN PARÁMETROS

El menú reutilizable

Transformá las cuatro instrucciones que muestran las opciones del menú en una función.

Tu función debe: llamarse mostrar_menu(), imprimir las cuatro opciones y ejecutarse una vez en cada vuelta del bucle.
💡 Pista: ¿cómo empezar?
Escribí def mostrar_menu(): antes del while. Mové adentro los print() del menú. Después, dentro del while, usá mostrar_menu().
MISIÓN 02 · PARÁMETROS

Un solo inventario

Actualmente, el inventario se imprime en distintos lugares. Reemplazá esos bloques por una función.

Tu función debe: llamarse mostrar_inventario(esmeraldas), recibir el saldo e imprimirlo. Llamala donde sea necesario.
💡 Pista: ¿qué recibe?
Podés usar def mostrar_inventario(esmeraldas): y, en la opción 1, llamarla con mostrar_inventario(esmeraldas). El nombre dentro de los paréntesis representa el dato recibido.
MISIÓN 03 · RETURN

Recolectá esmeraldas

En lugar de sumar directamente en el menú, creá una función que calcule el nuevo saldo y lo devuelva.

Tu función debe: llamarse recolectar(esmeraldas), sumar 5 y devolver el saldo nuevo con return. Guardá lo que devuelve.
💡 Pista: una línea clave
Dentro de la función: return esmeraldas + 5. Al llamarla: esmeraldas = recolectar(esmeraldas). Revisá la diferencia entre print y return.
